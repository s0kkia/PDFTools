# PDFTools 2.0

PDFTools 2.0.1 — настольное приложение для работы с PDF в Windows 10/11 x64. Интерфейс построен на Python и PySide6.

## Возможности

- Восстановление PDF (HotFix).
- Объединение и разделение документов.
- Рабочее пространство для страниц PDF с перестановкой и удалением страниц.
- Сравнение двух PDF с визуальным выделением различий.
- Штампы и текстовые водяные знаки.
- Работа с метаданными.
- Извлечение изображений и таблиц.
- История операций.
- Проверка, загрузка и установка обновлений с проверкой SHA256 и резервным откатом.

OCR и отдельная функция сжатия PDF исключены из версии 2.0.

## Установка и запуск

Скачайте архив `PDFTools_2.0_Windows_x64.zip` из GitHub Actions Artifacts или GitHub Releases и распакуйте его полностью в отдельную папку. Запускайте:

`PDFTools/PDFTools.exe`

**Важно:** не перемещайте EXE отдельно от папки с остальными файлами. Это portable-сборка в режиме one-folder, выбранная для ускорения запуска: Windows не распаковывает весь пакет заново при каждом старте.
